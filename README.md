# AgentBox

여러 AI 코딩 에이전트(Claude Code · Codex · OpenAI 호환 API · 로컬 LLM)를 하나의 데스크톱 앱에서 쓰는 바이브코딩 도구입니다.

## 다운로드

👉 **[최신 버전 다운로드 (Releases)](https://github.com/MKGameDeveloper/AgentBox-Releases/releases/latest)**

| OS | 파일 |
|----|------|
| Windows (x64) | `AgentBox-Setup-<버전>.exe` |

설치 후에는 새 버전이 나오면 앱에서 알림이 뜨고, **업데이트** 버튼으로 바로 설치할 수 있습니다.

> 아직 코드 서명이 되어 있지 않아 설치 시 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 설치됩니다.

## 주요 기능

- **AI 선택**: Claude Code, Codex, 기타 OpenAI 호환(Gemini/OpenRouter/DeepSeek/Groq/xAI/OpenAI), 로컬(Ollama/LM Studio/llama.cpp)
- **다중 계정 + 자동 전환**: 한도에 걸리면 다음 계정으로 자동 전환, 모든 계정이 한도면 가장 빨리 풀리는 시각에 자동 재개
- **컨텍스트 자동 압축**: 대화별로 켜고 끌 수 있음
- **분할 대화창**: 1 · 2 · 3 · 4 · 6개 창, 창마다 다른 프로젝트·AI
- **메인 탭**: 프로젝트 탭 + VS Code식 탐색기(자동 새로고침), 마크다운 렌더링, 코드 구문 강조

## 시작하기

1. 설정(좌측 하단 톱니) → **계정**에서 AI 계정 추가
2. 메인 탭에서 **폴더 열기** → 대화 시작
